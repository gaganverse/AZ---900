# 4. Azure Regions

## Definition

An Azure **region** is a **geographic area** containing one or more Azure datacenters.

## Why?

**Regions** allow you to deploy resources closer to users and help with:

- **Latency**
- **Compliance**
- **Availability**

## Example

You have customers in the **US**.

You may deploy your application to an **Azure region in the US**.

## When to Use

Choose a region based on:

- **User location**
- **Data residency**
- **Compliance**
- **Service availability**
- **Pricing**

## ⭐ Remember

**Region = Geographic location**
