
# 22. MFA / SSO

## MFA

### Definition

Multi-Factor Authentication requires **multiple verification factors**.

### Why?

Provides **stronger authentication**.

### Example

```text
Password
   +
Phone verification
```

### When to Use

**MFA** → **Improve authentication security**

---

## SSO (Single Sign-On)

### Definition

Allows a user to **authenticate once** and access multiple applications.

### Example

```text
Login once
    ↓
Microsoft 365
Azure
Teams
SharePoint
```

### When to Use

**SSO** → **Simplify access to multiple applications**
