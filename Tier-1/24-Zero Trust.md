
# 24. Zero Trust

## Definition

It's a security model based on: **Never trust, always verify.**

## Why?

Traditional security assumes internal users are trusted.

Zero Trust continuously verifies:

- **Identity**
- **Device**
- **Access**
- **Context**

## Example

Even if a user is inside the company network, access isn't automatically trusted.

## When to Use

Use Zero Trust principles when designing secure cloud environments.

## ⭐ Remember

- **Verify explicitly**
- **Use least privilege**
- **Assume breach**
