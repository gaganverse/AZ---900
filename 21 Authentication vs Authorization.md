## Authentication

### Definition

Authentication verifies **who you are**.

### Example

```text
Username + Password
        ↓
    Who are you?
```

### When to Use

Think:

**Authentication = Who?**

---

## Authorization

### Definition

Authorization determines **what you are allowed to do**.

### Example

```text
User → Can read Storage
User → Cannot delete Storage
```

### When to Use

Think:

**Authorization = What can you do?**
