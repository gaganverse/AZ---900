
# 3. Shared Responsibility Model

## Definition

Security responsibilities are **shared between Microsoft and the customer**.

## Why?

Moving to the cloud doesn't mean **Microsoft handles everything**.

## Example

With an **Azure VM**:

### Microsoft

- **Physical datacenter**
- **Physical network**
- **Physical servers**

### Customer

- **Data**
- **Applications**
- **Guest OS**
- **Access permissions**

## When to Use

Use this concept whenever an exam question asks:

**"Who is responsible for security?"**
